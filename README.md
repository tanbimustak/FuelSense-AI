# FuelSense AI

## AI-Powered Fuel Station Monitoring and Predictive Maintenance System

FuelSense AI is a Machine Learning-based system developed to analyze fuel station maintenance logs, predict equipment failures, monitor fuel conditions, and generate automated reports for preventive maintenance.

---

## Features

- AI-based Maintenance Log Analysis
- Machine Failure Prediction
- Fuel Level Monitoring
- Water Contamination Detection
- Machine Health Monitoring
- Automatic PDF Report Generation
- CSV Report Generation
- Predictive Maintenance using Machine Learning

---

## Technology Stack

- Python
- Pandas
- Scikit-learn
- ReportLab
- Machine Learning (Naive Bayes)

---

## Project Workflow

1. Read maintenance log
2. Analyze using Machine Learning
3. Predict issue category
4. Monitor machine status
5. Generate PDF & CSV reports
6. Send maintenance alerts

---

## Installation

```bash
git clone https://github.com/tanbimustak/FuelSense-AI.git
cd FuelSense-AI
pip install -r requirements.txt
python main.py
```
