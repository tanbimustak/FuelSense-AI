# ⛽ FuelSense AI

## AI-Powered Fuel Station Monitoring and Predictive Maintenance System

FuelSense AI is a Machine Learning-based application designed to analyze fuel station maintenance logs, predict equipment failures, monitor fuel conditions, and generate automated reports for preventive maintenance.

**Project Goal:** To improve fuel station operations through AI-powered monitoring, predictive maintenance, and automated reporting, helping reduce equipment downtime and improve operational efficiency.

---

## 🚀 Features

- 🤖 AI-Based Maintenance Log Analysis
- ⚙️ Machine Failure Prediction
- ⛽ Fuel Level Monitoring
- 💧 Water Contamination Detection
- 🛠️ Machine Health Monitoring
- 📄 Automatic PDF Report Generation
- 📊 CSV Report Generation
- 📧 Email Notification Support
- 🧠 Predictive Maintenance using Machine Learning

2. Analyze logs using Machine Learning

4. Monitor machine health
5. Detect fuel level and water contamination
6. Generate PDF & CSV reports
7. Send maintenance alerts

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/tanbimustak/FuelSense-AI.git
```

Move into the project folder

```bash
cd FuelSense-AI
```

Install the required libraries

```bash
pip install -r requirements.txt
```

Run the project

```bash
python main.py
```
